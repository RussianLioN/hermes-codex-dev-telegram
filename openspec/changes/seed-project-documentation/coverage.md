## Classification

| Status / evidence class | Значение | Пример / запрет вывода |
|---|---|---|
| Current source / SOURCE_ONLY | Прочитан текущий source, поведение не исполнено | Контракт root updater; наличие branch/backup checks не новый upgrade/restore test |
| Current tooling / NATIVE_LOCAL | Реально выполнен ограниченный CLI/index check | OpenSpec validation и scoped MemPalace retrieval; не product E2E |
| Draft / to-be | Предлагаемый нормативный product контракт, exact approval pending | Delta specs; не объявлять main as-built baseline |
| Historical / LOCAL_SYNTHETIC | Receipt fixture с fake IO/identity/clock | MOCK PR, toy controller, synthetic callback не live effect |
| Historical / NATIVE_LOCAL | Проверен реальный local component в ограниченном окружении | Local Kanban/targeted loader; не server acceptance и не новый запуск этого change |
| Historical / AUTHORIZED_CANARY | Реальное bounded испытание по отдельному разрешению | One-shot Linux/OS DAC; scope исчерпан, нельзя повторять по ссылке на receipt |
| Blocked / FAILED / NOT_RUN | Не выполнен полный обязательный criterion либо известен отказ | CLIENT_ROUTING_GATE_OPEN, broken stock lifecycle test, pending approval; parent не закрывается |
| LIVE_ACCEPTANCE | Полный exact revision criterion в разрешённой целевой среде с readback | Для нынешнего Telegram product не заявляется |

Fresh-context council другой сессии одной модели не независимые модели и не новый test run. Heuristic filtering не обещает отсутствие произвольных секретов. ORCH-01 / CRITICAL остаётся открыт независимо от полноты документации.
